Datos: — partidos de la Liga BetPlay tomados de la API pública de ESPN, con corte al —; se actualizan solos cada día. ESPN usa el nombre actual de cada club, así que La Equidad aparece como Inter Bogotá en toda la serie.

Modelo: regresión de Poisson con una fuerza de ataque y una de defensa por equipo, ventaja de local y más peso para los partidos recientes. No conoce lesiones, sanciones ni nóminas. La simulación sortea los goles de cada partido pendiente; un empate global en la final se define por penales con 50 % para cada uno.

Los escudos son ilustraciones propias con los colores de cada club, no los oficiales. Código en GitHub · API · Daniel Julián Díaz Riaño
